## The first launch will warn you

vectile is not code-signed, so your operating system cannot check who made the file and asks you
to confirm before opening it. Every build comes from this repository, and you can read the source.

### Windows

Defender SmartScreen shows a blue box that says Windows protected your PC. Click **More info**,
then **Run anyway**.

To stop the warning next time, right-click the downloaded file, open **Properties**, tick
**Unblock**, and click **Apply**.

### macOS

Gatekeeper says the app cannot be opened because Apple cannot check it for malicious software.
Right-click the app, choose **Open**, then click **Open** again in the dialog. Once is enough.
The same thing from a terminal:

```bash
xattr -d com.apple.quarantine /Applications/vectile.app
```

### Linux

The deb installs with:

```bash
sudo apt install ./vectile-linux-amd64.deb
```

The AppImage needs the execute bit:

```bash
chmod +x vectile-linux-amd64.AppImage
./vectile-linux-amd64.AppImage
```

## What happens next

1. **Add a model.** It turns your text into numbers, and the app downloads one for you from a
   short list. See [Models](/docs/models).
2. **Point it at a folder.** Notes, documents, books, or code. See [What you can
   index](/docs/sources).
3. **Index, then search.** Press <kbd>Ctrl</kbd>+<kbd>K</kbd> (<kbd>⌘</kbd>+<kbd>K</kbd> on
   macOS) and type a question. [First run](/docs/first-run) walks through all of it.

Indexing runs on your CPU, so the first pass over a large library takes a while.
