# Browse

Browse takes one collection and shows its chunks in order, grouped under the file they came from. Select a chunk and the pane on the right fetches its full text.

![The Browse view: a chunk stream grouped under sticky file headers, with checkboxes and a reading pane showing the selected chunk's full text](/img/screenshots/browse.png)

## Reading

Chunks load as you scroll, so Browse stays usable on a collection with 200,000 of them. File headers stay pinned.

## Deleting one chunk

Select chunks with the checkboxes, then use the bar above the list to delete them. Only those chunks and the numbers stored for them are removed; the rest of the file stays searchable.

One bad paragraph can go without losing the file.

Deleting is refused while an index run is in progress, on any collection. Let the run finish, or cancel it from the Index view or the tray.
