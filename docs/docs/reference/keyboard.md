# Keyboard shortcuts

| Keys | Where | Does |
|---|---|---|
| <kbd>Ctrl</kbd>+<kbd>K</kbd> / <kbd>⌘</kbd>+<kbd>K</kbd> | Everywhere | Focus the search box and jump to Search. |
| <kbd>Enter</kbd> | Search box | Run the query now instead of waiting. |
| <kbd>Esc</kbd> | Search box | Clear the query and the filters. |
| <kbd>Tab</kbd> / <kbd>Shift</kbd>+<kbd>Tab</kbd> | Everywhere | Move to the next or previous control. |
| <kbd>Space</kbd> / <kbd>Enter</kbd> | A switch | Flip it. |
| <kbd>↑</kbd> <kbd>↓</kbd> | An open dropdown | Move between options. |
| <kbd>Home</kbd> / <kbd>End</kbd> | An open dropdown | Jump to the first or last option. |
| <kbd>Enter</kbd> / <kbd>Space</kbd> | An open dropdown | Choose the highlighted option. |
| <kbd>Esc</kbd> | An open dropdown or dialog | Close it without choosing. |
| A letter key | An open dropdown | Jump to the first option starting with that letter. |
| <kbd>←</kbd> <kbd>→</kbd> | Settings rail | Move between sections. |
| <kbd>Home</kbd> / <kbd>End</kbd> | Settings rail | Jump to the first or last section. |
| <kbd>Enter</kbd> | A path field in Settings | Add the typed path to the list. |

## On macOS

Wherever this page says <kbd>Ctrl</kbd>, on macOS you press <kbd>⌘</kbd>. Nothing else differs.
