# vectile docs

The website at <https://d3ucey.github.io/vectile/>, built with [Docusaurus](https://docusaurus.io/).

## Local development

```bash
npm install
npm start
```

## Build

```bash
npm run build
```

Output goes to `docs/build`. The site deploys from `.github/workflows/deploy-docs.yml` on any push
to `main` that touches `docs/**`.
